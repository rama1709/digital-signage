CV Cahaya Mustika - Website Digital Signage & Office Equipment

CARA MENJALANKAN
1. Buka folder ini (CV-Cahaya-Mustika) di VS Code.
2. Klik kanan index.html > Open with Live Server (Go Live).

STRUKTUR
index.html, produk.html, portofolio.html, artikel.html, kontak.html
css/style.css      -> seluruh gaya website
js/script.js       -> navigasi, animasi reveal, FAQ, filter produk, dll.
assets/            -> logo, favicon, gambar produk & artikel

Catatan: jangan memindahkan file HTML keluar dari folder utama
agar path gambar tetap berfungsi.
